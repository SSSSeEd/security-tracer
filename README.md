# Security Tracer

攻撃と防御を「目で見て、手で動かして」学ぶ、情報セキュリティ学習サイトです。Cisco Packet Tracer のシミュレーションモードをお手本に、パケットの動きや攻撃の段階を図解とインタラクティブな実験台（ラボ）で確かめられます。iPhone の Safari を主な利用環境として設計しています。

## 中身
- **8コース・30レッスン**：ネットワーク基礎、暗号、認証、Web、マルウェア、脆弱性、防御と運用、ニュースの読み方
- **22の図解ラボ**：SQLインジェクション実行エンジン、本物の SHA-256 / AES / RSA / ECDSA、TLS 1.3、DNS キャッシュポイズニング、ワーム拡散モデル、ランサムウェアとバックアップ、CVSS v3.1 計算機、バッファオーバーフロー、ログ分析、キルチェーン/ATT&CK など
- **5本の攻撃シミュレーター**：スミッシング、偽 Wi‑Fi、SQLi、VPN 経由のランサムウェア、API 悪用
- **用語集**（約65語）、**クイズ**（間違えた用語を優先出題）、**注意喚起ニュース**（JPCERT/CC・IPA の一次情報のみ）

## 正確性のルール
- 解説・用語・ニュースには必ず出典（公的機関・標準化団体・一次情報）を付け、`js/data/sources.js` に確認日とともに登録する
- 出典で確認できないことは書かない。数値の目安やモデルは「単純化した例」「説明用の仮の値」と明記する
- 会社名・ドメイン・電話番号の例は架空のもの（example ドメイン、文書用 IP アドレス帯）を使う

## 構成
ビルド不要の静的サイトです。`index.html` を開くだけで動きます（GitHub Pages 対応）。

```
index.html          GitHub Pages 用の入口
css/style.css
js/core.js          ルーター、進捗保存、ウィジェット登録
js/data/*.js        出典・用語・コース・クイズ・シナリオ・ニュース
js/widgets/*.js     図解ラボ（ウィジェット）
js/views.js         各ページ
js/app.js           画面の枠と起動処理
```

進捗はブラウザの localStorage に保存されます（端末ごと）。

## ラボを足すとき

1. `js/widgets/<分野>-<話題>.js` に `ST.widget("id", { title, group, name, desc, order, mount })` を書く。`group` は `ST.LAB_GROUPS`（js/views.js）の id。`group` があるウィジェットだけがラボ（一覧に載り、ヘッダに LAB チップが出る）。攻撃シミュレーターのように一覧に載せないものは `group` を付けない。ラボ一覧は登録内容から自動で組み立てられる。
2. `index.html` に script タグを足す（`js/widgets/_kit.js` の後、`js/views.js` の前）。
3. `node tools/check.js` が `OK` になることを確認してからコミットする（script 一覧、ウィジェットとレッスン・用語・出典・クイズの参照切れを検査する）。
